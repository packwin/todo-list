# Todo List!
A todo list web app built to apply and showcase the skills learnt during the Odin Project's "Organizing Your JavaScript Code" section of the JavaScript course.
These skills include:
- using Object Oriented Programming Principles
- using JavaScript Objects, Factories, Modules, and Classes
- using ES6 Modules and importing and exporting between files
- using npm, Webpack, and other packages
- using JSON and the Web Storage API
